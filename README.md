# MNIST Handwritten Digit Recognition using TensorFlow

A deep learning project that uses the **MNIST dataset** to recognize handwritten digits (0–9) with a neural network built in **TensorFlow**.

---

## 🧠 Overview

This project demonstrates how to build, train, and evaluate a neural network for handwritten digit recognition. The MNIST dataset consists of 70,000 grayscale images of digits, each sized 28x28 pixels. The model learns to classify these images into one of ten categories (0–9).

---

## 🚀 Features

- Uses the **MNIST dataset** from TensorFlow/Keras datasets  
- Implements a **feedforward neural network**  
- Includes **data preprocessing, training, and evaluation** steps  
- Visualizes **training accuracy and loss**  
- Predicts and displays **sample test results**
